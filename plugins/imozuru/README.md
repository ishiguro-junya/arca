# imozuru for Codex

MaryCache の [imozuru](https://github.com/MaryCache/imozuru) を Codex 向けに移植した非公式プラグインです。
未知の分野の用語・人物・媒体を見つけ、引用・リンク・著者をたどって原文を集めます。
引用を原文と照合したレポート、調査記録のダッシュボード、RSS の新着確認を含みます。

## 導入

Arca のルートで実行します。

```sh
codex plugin marketplace add .
codex plugin add imozuru@arca
codex plugin list --available --marketplace arca --json
```

最後の出力で `imozuru@arca` が `installed: true`、`enabled: true` になれば導入済みです。
次のターンから利用でき、一覧に出ない場合は新しいチャットか Codex の再起動で確認してください。
ローカルのマーケットプレイスから導入するため、この作業ディレクトリを残してください。

## 使い方

Codex のスキル一覧で `imozuru` を選ぶか、スキル名を指定します。
プラグインの一覧では `imozuru:imozuru` と表示される場合もあります。

```text
$imozuru Gaussian Splatting を、用語・人物・引用から芋づる式に調べて。
```

```text
$imozuru watch react 今週の新着を確認して。
```

```text
imozuru で、保存済みの調査からダッシュボードを更新して。
```

既定の保存先は `~/research/<話題>/` です。
別の保存先も指定できます。
結果は `map.md`・`log.md`・`sources/`・検索と取得のログ・`report.html`・`digest.html` に残り、保存先の親に `index.html` ができます。
終了条件は論点の充足、情報の飽和、4周の上限、取得不可、ユーザー指定の上限です。
新着確認は1回の実行が既定で、定期実行は明示的に依頼した場合に設定します。

## 環境

Python 3.10 以上が必要です。
Python パッケージの追加は不要です。
macOS 付属の Python は古い場合があるため、Codex は利用可能な対応インタープリターを確認してから実行します。
通常の Web 検索は Codex の検索機能を使い、原文の取得・引用照合・HTML 生成は同梱スクリプトで行います。

PDF の文字起こしには `pdftotext`、スキャン PDF の OCR には `pdftoppm` と `tesseract`、YouTube 字幕には `yt-dlp` が必要です。
HTML は標準ライブラリで取得でき、`ax` がある場合だけ本文整形に使います。
任意コマンドがない場合は、その形式を取得できなかった理由を残します。
OpenAlex の利用に API キーや課金設定を追加しません。

## Codex への適応

- 検索は同じエージェントによる異なる2方針の順次実行で進められます。
  サブエージェントはユーザーと実行環境の指示が許す場合だけ使い、モデルは親から継承します。
- Claude 固有のツール・モデル・導入方法への依存を除いています。
  入口は短く保ち、調査・記録形式・レポート・新着確認・道具の説明を参照ファイルへ分けています。
- ダッシュボードの版はプラグインの [plugin.json](plugin.json) から読み取ります。
  感想フォームは、利用者が `IMOZURU_FEEDBACK_FORM` を設定した場合だけ表示します。
- 静的 HTML の生成にサーバー起動は不要です。
  ローカル配信・スマートフォンへの中継・成果物の公開は、それぞれ依頼された場合に行います。

詳しい実行方法は [tools.md](skills/imozuru/references/tools.md) にあります。
原文や引用の保存は利用条件と実行環境の規則に従い、成果物を自動で公開しません。
引用の機械照合は原文内の存在を検査するもので、解説の正しさを保証するものではありません。

## 検証

プラグインのディレクトリで、対応する Python を指定して実行します。

```sh
python3 -m unittest discover -s tests
```

テストは引用照合、HTML 生成、原文の保持、取得先とファイルの境界、RSS、ダッシュボードの配信制御を含みます。
一部は一時的なループバックサーバーを使うため、ソケットを制限する実行環境では権限が必要です。
macOS の一時領域が `/var` などのシンボリックリンクを経由する場合は、`TMPDIR=/private/tmp` を付けて実行します。
束の出力先にシンボリックリンクを含めないという実装の検査に合わせるためです。
実際の外部検索と Codex による調査の品質は、これらの単体テストとは別に確認する必要があります。
実行結果は [検証記録](docs/validation.md) に残します。
