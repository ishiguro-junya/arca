- 補助ツールは 108 テストが成功し、厳密な TypeScript 型チェックも成功しました。
- 状態遷移図は 150 テスト中 140 件成功、失敗 0 件、スキップ 10 件でした。
  スキップは Linux の障害注入 5 件、PID 名前空間 1 件、追加フォント 3 件、実 mise 経由のツール検出 1 件です。
  TLC と描画依存は実物を使い、mise の導入分岐は模擬環境でも確認しました。
- 57 スキルのメタデータ・呼び出し設定、23 手順集、200 ローカルリンク、プラグインの JSON Schema、166 原典ファイルのハッシュを確認しました。

- 原典の GNU stat/date 修正に相当する処理は、Codex 版では Python の時刻取得と BSD/GNU date のフォールバックで対応済みです。

状態遷移図の初回テストでは、macOS の一時パスの別名、Java の日本語診断文、Linux 専用 LD_PRELOAD の前提に起因する失敗がありました。
テストの一時パスを実パスに統一し、Java の診断文を英語に限定しない検証へ修正しました。
Linux 専用の障害注入テストは、他の OS で実行済みと扱わずスキップします。
描画パッケージは公式 npm registry の安定版を確認し、TLC の公式リリースと配布ファイルのハッシュも照合しています。
依存関係と Java は一時ディレクトリに配置し、ユーザーの通常の実行環境へは追加していません。

新しいスキルの別チャットでの一連の実行、動画要約の実際の動画生成、ユーザーの実プロジェクトの形式検証は未実施です。
